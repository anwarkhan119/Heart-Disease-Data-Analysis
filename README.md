# Heart-Disease-Data-Analysis
Exploratory Data Analysis of a Heart Disease dataset using Python, Pandas, NumPy, Matplotlib, and Seaborn to identify patterns, relationships, and important health-related insights.
# ❤️ Heart Disease Data Analysis

## 📌 About the Project

This project focuses on performing **Exploratory Data Analysis (EDA)** on a Heart Disease dataset using Python.

The main objective is to explore the dataset, understand the distribution of different health-related features, identify relationships between variables, and find patterns associated with heart disease.

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Analysis Performed

* Data loading and understanding
* Data cleaning
* Checking missing values
* Descriptive statistical analysis
* Univariate analysis
* Bivariate analysis
* Correlation analysis
* Data visualization
* Distribution analysis
* Feature relationship analysis

## 📈 Visualizations

Different visualizations were created using Matplotlib and Seaborn, including:

* Histograms
* Count plots
* Box plots
* Scatter plots
* Bar plots
* Correlation heatmap

## 🔍 Key Objective

The objective of this analysis is to understand how different features such as **age, sex, chest pain, blood pressure, cholesterol, maximum heart rate, and other health-related factors** are associated with the presence of heart disease.
